# Chrono-Trader 사용 가이드

이 가이드는 Chrono-Trader 애플리케이션의 다양한 모드를 사용하는 방법에 대한 자세한 지침을 제공합니다.

## ⏱ 스케줄 운영 (`intraday`, `morning-report`)

운영(스케줄) 실행은 `scripts/run_scheduled.py`를 엔트리포인트로 사용하는 것을 권장합니다. (`refresh-db` → 추론, 워치독/신선도 게이트, MinRec/워치온리 폴백으로 1건 이상 출력 보장)

권장 스케줄러:
- systemd (user timers): `deploy/systemd/README.md` 참고

수동 실행 예시:
```bash
# 최근 캔들 DB 갱신 (네트워크 필요. 오프라인이면 --offline_ok로 안전 종료)
python main.py --mode refresh-db --refresh_days 3 --offline_ok

# 인트라데이(4시간) 추론
python main.py --mode intraday --min_k 1 --limit 8

# 오전 8시 리포트 추론
python main.py --mode morning-report --min_k 1 --limit 8
```

운영 계약(Exit code/아티팩트/폴백):
- `OPS_ACCEPTANCE.md`

## 🚀 일일 예측 (`daily`)

이 모드는 일일 운영을 위한 기본 모드입니다. 최신 데이터에 대한 경량 파인튜닝을 수행하고 새로운 예측을 생성합니다.

**목적:**
-   최신 시장 동향으로 모델을 빠르게 업데이트합니다.
-   새로운 거래 추천 및 잠재적 급등 예측을 생성합니다.
-   매일 자동으로 실행되도록 설계되었습니다.

**명령어:**
```bash
python main.py --mode daily
```

**옵션:**
-   `--daily_epochs <N>`: 경량 파인튜닝을 위한 에포크 수를 지정합니다. 기본값은 `2`입니다. 프로세스를 빠르게 유지하고 단기적인 노이즈에 과적합되는 것을 방지하기 위해 작은 숫자를 권장합니다.

**예시:**
```bash
# 3 에포크로 일일 모드 실행 (파인튜닝 포함)
python main.py --mode daily --daily_epochs 3
```

## 🏋️‍♂️ 전체 모델 훈련 (`train`)

이 모드는 모델에 대한 심층적이고 광범위한 훈련을 수행하기 위한 것입니다. 주기적으로(예: 매주 또는 매월) 또는 시장 역학이 크게 변경되었다고 판단될 때 실행해야 합니다.

**목적:**
-   모델을 처음부터 훈련하거나 대규모 데이터셋으로 심층 재훈련을 수행합니다.
-   Optuna를 사용하여 최적의 하이퍼파라미터를 찾습니다(선택 사항).
-   이것은 시간이 많이 소요되는 프로세스입니다.

**명령어:**
```bash
python main.py --mode train
```

**옵션:**
-   `--epochs <N>`: 전체 훈련 에포크 수를 오버라이드합니다. (기본값: `config.Gan.EPOCHS`)
-   `--tune`: Optuna 하이퍼파라미터 튜닝을 먼저 수행한 뒤, 최적 파라미터로 학습을 진행합니다.
-   `--no_collect`: 네트워크 데이터 수집을 건너뛰고 DB에 있는 데이터만으로 학습합니다(오프라인/안정성 권장).
-   `--offline_ok`: 수집 실패가 나도 계속 진행합니다(주로 ops/오프라인 환경용).

**Optuna (고급) 환경변수:**
- `AETHER_OPTUNA_TRIALS`: trial 수 (기본 `50`)
- `AETHER_OPTUNA_STORAGE`: 저장소 URL (권장 `sqlite:///analysis/optuna_full.db`)
- `AETHER_OPTUNA_STUDY_NAME`: 스터디 이름 (기본 `aether_gan_tune`)
- `AETHER_OPTUNA_LOAD_IF_EXISTS=1`: 기존 스터디 이어서 실행
- `AETHER_OPTUNA_TIMEOUT_SEC`: 전체 제한 시간(초)
- `AETHER_OPTUNA_N_JOBS`: 병렬도 (CPU에서는 `1` 권장)

**예시:**
```bash
# 30 에포크로 전체 훈련 실행
python main.py --mode train --epochs 30

# 하이퍼파라미터 튜닝 후 최적의 파라미터로 훈련 실행
python main.py --mode train --tune --no_collect --offline_ok
```

## 📊 백테스팅 (`backtest`)

이 모드를 사용하면 과거 데이터에 대한 모델의 성능을 평가할 수 있습니다.

**목적:**
-   과거 기간 동안의 거래를 시뮬레이션하여 모델의 효율성을 측정합니다.
-   승률, 샤프 비율, 최대 낙폭과 같은 주요 성능 지표를 계산합니다.

**명령어:**
```bash
python main.py --mode backtest --days <N>
```

**옵션:**
-   `--days <N>`: **(필수)** 백테스트를 실행할 과거 일수입니다.

**예시:**
```bash
# 지난 30일 동안 백테스트 실행
python main.py --mode backtest --days 30
```

**더 빠른 평가 / 자동화:**
```bash
# 백테스트 suite가 analysis/에 JSON 아티팩트를 남깁니다.
python scripts/eval_suite.py --days 30 --stride_hours 4 --tag eval_30d_4h --no_telegram
```

## 🛠️ 기타 유틸리티 모드

-   **`init_db`**: 데이터베이스 스키마를 초기화합니다. 프로젝트를 처음 설정할 때 한 번 실행합니다.
    ```bash
    python main.py --mode init_db
    ```
-   **`collect-all`**: 구성에 정의된 모든 시장에 대한 과거 데이터를 수집합니다.
    ```bash
    python main.py --mode collect-all --days 90
    ```
-   **`train-pump`**: 특히 급등 예측 모델을 훈련합니다.
    ```bash
    python main.py --mode train-pump
    ```
-   **`find-pumps`**: 훈련 없이 급등 예측 로직만 실행합니다.
    ```bash
    python main.py --mode find-pumps
    ```
